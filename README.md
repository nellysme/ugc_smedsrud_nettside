# 🎥 UGC Smedsrud – Offisiell nettside

Dette er den offisielle nettsiden for **UGC Smedsrud**, laget av søstrene Nelly og Abelone. Vi er kreative innholdsskapere som lager autentiske og engasjerende UGC-videoer (User Generated Content) for merkevarer.

## 🚧 Status

✅ Nettsiden er under utvikling – flere funksjoner og videoer legges til etter hvert.

## 🌟 Hva nettsiden inneholder

- Om oss: Hvem vi er og hva vi tilbyr
- Eksempler på UGC-videoer (15–60 sek)
- Kamera- og redigeringsutstyr vi bruker
- Kontaktinformasjon og samarbeidsskjema
- Lenker til TikTok og annen relevant plattform
